# 前端工作空间与实际验收

API 门面保留原导出；契约、共享传输和 auth/queries/ingestion/assets/administration 分别维护。`navigation.ts` 统一入口、分组、标题和权限。`DialogFrame` 使用原生 dialog 的模态焦点及 inert，不再逐页面实现浮层；移动侧栏也复用它。Skip link、焦点样式、减少动画和真实加载状态共用。

查询保留原始范围、历史恢复和续问，防止重复提交，Ctrl/⌘+Enter 在 IME 输入完成后可提交。任务在后台运行；页面不编造阶段进度或要求用户输入 JSON。页面只展示实际任务、状态、证据和错误。

2026-10-03 已通过 lint、TypeScript 与 Vite 构建，并正常发布带 Hash 的静态资产。真实 computer use 检查管理员十三入口，分别使用桌面 1442×710 与窄屏 390×844；主内容区唯一、页面无横向溢出。实际打开已有查询原文、上传及查询历史弹窗，检查焦点、Esc/返回焦点、密级选项和移动导航。没有提交新模型查询、上传或修改业务数据。

默认新部署 CI 的浏览器 smoke 已调整为当前页面命名与原生弹窗，但未在本机新空环境执行；不能将现存 target 的页面检查当成 CI 全链通过。原始 AX、截图、布局读回、构建记录和权限 SQL 保存于本地发布证据目录 `work/product-release-20261003`，公共 README 仅使用无隐私的合成资料截图。

当前真实模型失败、质量缺口和未完成规模评估保持 [验收记录](README.md) 的状态。

## 可重现安装收尾

GitHub 的 npm 11.19 曾真实拒绝旧锁文件，缺少两个 @emnapi bundled 依赖条目。使用相同 npm 在新空副本复现后，通过正常 lock-only 重建修正包路径；共同包版本和完整性保持不变。新空副本的严格安装、Linux/x64/glibc 目标依赖解析、普通安装、lint/类型/构建及完整审计通过，0 漏洞。平台目标解析不等于真实 Linux 构建；云端结果以 Actions 对应提交为准。未添加脚本放行或削弱审计。原失败与修复报告保存于本地发布证据目录。
